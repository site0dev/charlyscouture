Gestion de toutes les photos

Toutes les images actuellement utilisées par le site sont regroupées ici : Hero, La Maison, chaque service et chaque photo de la galerie. Vous pouvez sélectionner une photo depuis votre galerie, la prévisualiser puis la remplacer. Les nouvelles adresses sont enregistrées dans Supabase et restent après actualisation.

Remplacement propre

Le fichier choisi est envoyé dans le stockage Supabase. Pour les images déjà stockées dans le bucket models, l'ancien fichier est supprimé lorsqu'il peut être identifié. Les anciennes images provenant d'Internet ne sont pas téléchargées ni conservées dans votre stockage.
